# 직원정보 빠른 조회

직원 목록의 원본은 운영 직원정보 시트(직원·아웃소싱·타업체, 활성화된 행)입니다.
`getProductionPlanStaff`는 로그인 검증 후 `production_plan_staff_cache`의 마지막 정상 목록을 반환합니다.
서버 재시작·새 브라우저에서도 시트 호출을 기다리지 않습니다.

목록이 1분 이상 지나면 `EdgeRuntime.waitUntil`로 원본을 뒤에서 갱신합니다.
DB의 조건부 갱신으로 3분간의 갱신 권한을 얻은 요청만 시트를 읽습니다.
원본 호출은 25초로 제한하며, 실패해도 정상 목록은 유지합니다.
갱신 권한을 잃은 오래된 응답은 새 목록을 덮어쓰지 않습니다.
시트 변경분은 서버의 후속 조회와 화면의 기존 1분 자동 갱신으로 반영됩니다.

배포 순서: 테이블 생성 → 현재 원본으로 목록 채우기 → Edge Function 배포 → 조회 검증.
미리 채우지 않은 경우에만 첫 요청이 원본을 기다립니다.
브라우저가 직접 테이블에 접근할 권한은 없으며 기존 로그인 검증을 그대로 사용합니다.
원본 목록에서 이름·구분·표시명만 보관하고 사번·입사일 등은 보관하지 않습니다.
