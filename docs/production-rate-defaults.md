# 2026-11-10 생산량 기준 입력

확정 기준은 **8시간 기준값만 시간당으로 환산**하며 수동 실크의 2도는 제품의 두 번째 공정입니다.

| 공정 | 시간당 생산량 |
|---|---:|
| 수동 실크 1도 | 1,250 |
| 수동 실크 2도 | 812.5 |
| 자동 실크 | 2,250 |
| 박 1·2·3도 | 700 |

`tools/production-rate-defaults.mjs`는 기존 평균·공정별·자동 생산량 중 하나라도 양수가 있는 제품을 보존합니다.
빈 제품의 각 작업 그룹 마지막 공정 번호로 수동 기준을 매칭하며 박/실크 종류를 확인합니다.
수동 실크 3·4도와 공정 구분 미지정 항목은 임의로 계산하지 않습니다. 코팅·라벨은 대상이 아닙니다.
자동 기준은 `automaticHourlyProductionRate`에 별도로 저장합니다. 생산계획에서 자동화를 선택한 실크 공정에만 사용합니다.

DB 적용은 현재 버전 잠금과 제품 공정·생산량의 변경 전 값 대조 후 원본 데이터의 생산량 필드만 합칩니다.
`commit_dev_state_mutation`으로 상태 버전을 갱신하고 `backfillProductProductionRates` 동기화 항목을 남깁니다.
시트는 일회용 서버 토큰을 검증하고 미리보기에서 충돌을 확인한 뒤 생산량 세 열만 갱신합니다.
동일 값의 재실행은 변경하지 않으며 다른 양수 값이나 누락 제품이 있으면 쓰기 전에 중단합니다.
운영 제품과 시트의 변경 전 자료는 저장소 밖의 비공개 보관본을 사용하며 제품 실데이터는 커밋하지 않습니다.

박 작업은 인쇄와 포장 작업자를 동일하게 저장하고 화면에서 한 번만 선택합니다.
실크·자동화의 인쇄/포장 선택은 분리되어 있습니다.
