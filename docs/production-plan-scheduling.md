# 생산계획 자동 근무시간 (2026-10-16)

- 출근하는 날의 계획 근무시간은 평일·토요일·일요일·공휴일 모두 최소 8시간이다. 쉬는 날은 0시간이고, 3시간 등 부분 출근은 배정하지 않는다. 기본 근무는 평일 8시간이다. 납기를 당기기 위한 불필요한 연장근무는 하지 않는다.
- 선택 날짜부터 납기일 당일까지를 사용한다. 평일 8시간 → 8시간 30분 → 9시간 → 9시간 30분 → 10시간의 순서로 더 낮은 근무시간 상한부터 검토한다. 긴 평일 근무를 한 주에 몰지 않고 나누며, 모든 계획 근무시간은 30분 단위다. 9시간 47분처럼 분 단위 계획을 만들지 않는다. 마지막 날의 잔량은 정확히 생산한다.
- 월요일~일요일을 한 주로 센다. 그 주에 향후 배정하는 평일 10시간을 포함해 3일 이상이 되면 납기 안에 있는 같은 주 토요일 8시간으로 대체하고 평일을 다시 계산한다. 토요일은 한 번에 하나씩 추가해 다시 평가하며, 더 낮은 근무로 분산 가능하면 불필요한 토요일을 추가하지 않는다. 공휴일 토요일이나 납기 뒤 토요일은 대체일로 쓰지 않는다. 토요일을 넣어도 10시간 집중을 피할 수 없으면 화면에 납기/물량 조정 필요를 표시한다.
- 과거 근무는 같은 브라우저·공장·작업자의 선택 날짜 전날까지 저장한 실 근무시간으로 판단한다. 실 근무시간이 아직 없으면 기계가 배정된 저장 계획의 근무시간을 참고하고, 실제 0시간을 입력한 날은 0시간을 우선한다. 발주와 공정이 달라도 같은 작업자의 시간은 합치며 활성 공정과 공정별 보관본의 중복은 제외한다. 다른 공장·작업자·미래 기록은 근무 부담 계산에 섞지 않는다. 생산량 집계는 기존대로 발주·제품·공정별로 구분한다. 실제 근무시간과 생산 실적을 수정하거나 추천 시간을 실제 실적으로 저장하지 않는다.
- 일반적인 부족 물량은 토요일 → 일요일 → 공휴일 순으로 배정하고 필요하면 최대 10시간까지 검토한다. 3일 이상 10시간을 줄이기 위한 토요일 대체는 8시간을 확보한다. 휴일도 8시간부터 시작해 연장은 30분 단위로 정한다. 불필요한 휴일 근무는 8시간 미만으로 줄이지 않고 해당 근무일 전체를 휴무로 처리한다.
- 같은 제품·공정이며 작업자·기계 배정이 호환되는 차수 번호가 있는 진행 발주는 차수 순서로 이어 생산한다. 44차 마지막 날에 3시간이 필요하면 45차를 나머지 5시간에 배정하고 하루 근무는 8시간으로 센다. 공정·기계·작업자가 다른 저장 배정은 자동 연결하지 않는다. 여러 제품·기계·작업자의 동시 배정이나 급여 금액 계산은 포함하지 않는다. 주말보다 공휴일을 더 피한다는 사용자 비용 우선순위를 적용한다.
- 발주량에서 **선택 날짜 전날까지** 같은 발주·제품·공정/공정 묶음의 저장된 금일 생산량을 뺀다. 오늘의 목표는 오늘 실적 입력 때문에 움직이지 않는다. 다른 공장 저장본도 포함한다. 실크·자동화는 같은 인쇄 공정의 실적으로 함께 합산하고 박 인쇄는 분리한다.
- 자료 범위는 현재 브라우저의 계획 저장본이다. 서버 실적/입고량/출고량을 생산 실적으로 간주하지 않는다.
- 일반 생산일 목표는 500개 단위로 내린다. 마지막 생산일만 정확한 잔량을 생산하며, 발주량을 초과하지 않는다. 마지막 날의 기본 계획 근무시간도 8시간이다. 생산 순수 소요시간과 근무 배정시간은 다르다.
- 매일 납기는 일일 필수량을 유지한다. 근무일 8시간을 우선하되 일일 최소량을 못 채우면 30분 단위로 10시간 한도에서 연장한다. 필수량을 낮춰 토요일로 옮기지 않는다. 필수량 때문에 주 3일 이상 10시간이 불가피한 경우 그 이유를 표시한다. 주말·공휴일은 기본 휴무다. 일일 최소량을 마지막 잔량보다 크게 강제하지 않는다.
- 납기일이 없으면 해당 날짜의 평일 8시간 목표만 제안하고 완료일을 확정하지 않는다. 지정 납기는 선택 날짜가 납기 당일까지인 경우에만 계획을 표시하고 다음 날부터는 저장된 계획도 목록에서 제외한다. 저장 원문과 일별 실적은 삭제하지 않으며 이전 날짜로 조회하거나 납기를 연장하면 다시 볼 수 있다. 종료일이 없는 매일 납기는 첫 저장 배정일 또는 마지막 저장 실적 다음 날부터 잔여 수량을 평일 계획으로 배분한 예상 완료일까지 표시한다. 주말·공휴일, 일일 최소량, 최대 10시간, 마지막 잔량 정확 생산 규칙을 동일하게 적용한다. 날짜 조회만으로 예상 완료일을 뒤로 미루지 않는다.
- 10시간/휴일까지 사용해도 부족하면 부족 수량을 표시하며 완료 예정일을 만들어 넣지 않는다.
- 상세 총 소요 시간(전체 발주량/등록 속도)과 누적 시간 합산은 유지한다. 잔여 작업일은 `(발주량-누적 생산량)/등록 속도/8`로 계산해 실제 생산 진척을 반영한다. 근무시간만 늘었다고 생산 실적이 증가한 것으로 보지 않는다. 일일 목표 시간은 계획 근무시간, 지정 납기 일일 필수량은 오늘 목표량과 일치한다.
- 실제 생산량·근무시간은 직접 입력한 실적만 저장한다. 추천 계획을 실제 실적으로 저장하지 않는다.

## 달력

2026·2027년 대한민국 공휴일과 대체공휴일을 내장했다. 토/일요일과 지정 공휴일이 겹치면 공휴일로 분류한다. 매주 일요일은 사용자가 정한 주말 분류를 따른다.

회사 휴무일은 선택적으로 `SEUNGJIN_CONFIG.PRODUCTION_PLAN_HOLIDAYS`의 `YYYY-MM-DD` 배열로 추가할 수 있다. 현재 회사별 휴무일 자료는 별도로 등록되지 않았다. 미지원 연도는 공휴일이 없다고 가정하지 않고 계산 불가로 표시한다. 임시공휴일 추가 지정 시 내장 자료를 갱신해야 한다.

## 날짜별 설정

- 저장된 계획이 없는 날짜는 같은 공장·발주의 가장 최근 이전 저장본에서 인쇄 유형·공정/공정 묶음·기계번호만 이어받는다. 전날 저장이 없으면 마지막 저장 날짜를 사용한다.
- 해당 날짜의 저장본이 우선한다. 직접 미배정으로 저장한 기계는 미배정을 유지하며, 해당 인쇄 유형에서 사용할 수 없는 기계는 미배정으로 처리한다. 다른 공장·발주와 미래 날짜의 설정은 가져오지 않는다.
- 생산량·실 근무시간·메모·수정 LOSS 등 날짜별 입력은 복사하지 않는다.

- 오브제는 같은 공장·발주에서 처음 기계를 배정하거나 실제 생산량/근무시간을 저장한 날짜 이전의 미배정 기본 행을 목록·계획 합계에서 제외한다. 이전 저장본도 기계·실적이 없으면 동일하게 제외하며 저장 원문은 변경하지 않는다. 실제 입력·배정이 있는 날짜와 시작일 이후 설정 이월은 유지한다.

- 누적 생산량 바로 옆에 잔여 수량을 읽기 전용으로 표시한다. 발주량에서 선택 날짜까지 누적 생산량을 빼며 최소 0개다. 금일 생산량 편집 시 즉시 갱신한다.
- 날짜 선택란 옆에 요일을 표시하고 직접 선택·이전·다음·오늘 이동 시 갱신한다. 날짜 전용 값을 UTC로 해석해 시간대에 따른 요일 오차를 피한다.

## 발주 선택

- 제품명 아래 발주 선택란에서 같은 제품·인쇄 유형의 진행 중인 발주를 선택한다. 완료·취소·잔량 0·표시 기간 이후 발주는 제외한다.
- 발주를 바꾸면 해당 발주의 목표·누적 실적·잔여 수량을 계산하며 새 발주에 이전 실적을 복사하지 않는다. 선택 날짜의 발주별 편집 내용은 전환 중 보관하고 계획 저장 시 함께 저장한다.
- 같은 날짜에 여러 발주를 저장해도 기존 저장 키를 유지한다. 선택한 발주를 jobs 첫 항목으로 저장하고 나머지 발주의 원본 실적을 보존한다. 날짜·공장을 바꾸면 임시 편집 상태를 초기화하며 저장된 선택과 실적을 불러온다.

- 날짜를 직접 선택하거나 이전·다음·오늘로 이동할 때 세부사항의 열림·닫힘 상태를 유지한다. 새 날짜의 행 ID로 열림 상태를 연결하며 입력값은 그 날짜의 저장본 또는 새 계획을 불러온다.

## 발주 간 이어 작업

- 발주별 완료 전날까지 실제 생산량을 따로 빼고, 앞 발주의 잔량을 끝낸 날에만 남은 시간을 다음 발주에 넘긴다. 일반 생산 목표의 500개 내림과 마지막 잔량 정확 생산을 유지한다. 발주별 배정시간도 30분 단위이며 두 발주의 합계는 하루 근무시간을 넘지 않는다.
- 발주 선택을 바꿔도 동일한 하루 배분을 보여준다. 표의 작업시간과 상세 일일 목표 시간은 하루 전체 근무시간이고 상세 안내에 발주별 시간·수량을 표시한다. 상단 하루 목표는 연결된 발주들의 합계다.
- 실 근무시간과 금일 생산량은 해당 발주에 실제 투입한 값만 각각 입력한다. 44차 3시간, 45차 5시간이면 각각 기록하고 누적 실적은 섞지 않는다. 추천 목표를 실제 생산량으로 저장하지 않는다.
- 다음 날짜에 앞 발주 생산이 완료되어 있으면 아직 생산할 발주를 기본 선택한다. 같은 날 저장했던 발주는 이전처럼 선택해 조회할 수 있다. 앞 발주에 연결 작업을 저장했으면 다음 발주도 해당 기계·공정을 이어받는다.
- 일일 필수량은 그대로 유지한다. 평일 연결 시간만으로 다음 발주의 필수량을 충족하지 못하면 부족량을 표시하고 필수량을 낮추지 않는다. 앞 발주가 납기 내 완료되지 못하면 다음 발주도 독립적으로 겹쳐 배정하지 않는다.
