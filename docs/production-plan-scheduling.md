# 생산계획 자동 근무시간 (2026-10-15)

- 기본 근무는 평일 8시간이다. 납기를 당기기 위한 불필요한 연장근무는 하지 않는다.
- 선택 날짜부터 납기일 당일까지를 사용한다. 평일 8시간, 평일 최대 10시간, 주말 최대 10시간, 공휴일 최대 10시간 순으로 생산 가능량을 확보한다. 연장은 분 단위로 줄여 비교하며, 같은 연장시간이면 앞 날짜에 배정한다.
- 이는 한 발주/공정의 근무 제안이다. 여러 발주·기계·작업자의 동시 배정이나 급여 금액 계산은 포함하지 않는다. 주말보다 공휴일을 더 피한다는 사용자 비용 우선순위를 적용한다.
- 발주량에서 **선택 날짜 전날까지** 같은 발주·제품·공정/공정 묶음의 저장된 금일 생산량을 뺀다. 오늘의 목표는 오늘 실적 입력 때문에 움직이지 않는다. 다른 공장 저장본도 포함한다. 실크·자동화는 같은 인쇄 공정의 실적으로 함께 합산하고 박 인쇄는 분리한다.
- 자료 범위는 현재 브라우저의 계획 저장본이다. 서버 실적/입고량/출고량을 생산 실적으로 간주하지 않는다.
- 일반 생산일 목표는 500개 단위로 내린다. 마지막 생산일만 정확한 잔량을 생산하며, 발주량을 초과하지 않는다. 마지막 날의 기본 계획 근무시간도 8시간이다. 생산 순수 소요시간과 근무 배정시간은 다르다.
- 매일 납기는 근무일 8시간을 우선하되 일일 최소량을 못 채우면 10시간 한도에서 연장한다. 주말·공휴일은 기본 휴무다. 일일 최소량을 마지막 잔량보다 크게 강제하지 않는다.
- 납기일이 없으면 해당 날짜의 평일 8시간 목표만 제안하고 완료일을 확정하지 않는다. 지정 납기는 선택 날짜가 납기 당일까지인 경우에만 계획을 표시하고 다음 날부터는 저장된 계획도 목록에서 제외한다. 저장 원문과 일별 실적은 삭제하지 않으며 이전 날짜로 조회하거나 납기를 연장하면 다시 볼 수 있다. 종료일이 없는 매일 납기는 첫 저장 배정일 또는 마지막 저장 실적 다음 날부터 잔여 수량을 평일 계획으로 배분한 예상 완료일까지 표시한다. 주말·공휴일, 일일 최소량, 최대 10시간, 마지막 잔량 정확 생산 규칙을 동일하게 적용한다. 날짜 조회만으로 예상 완료일을 뒤로 미루지 않는다.
- 10시간/휴일까지 사용해도 부족하면 부족 수량을 표시하며 완료 예정일을 만들어 넣지 않는다.
- 상세 총 소요 시간(전체 발주량/등록 속도)과 누적 시간 합산은 유지한다. 잔여 작업일은 `(발주량-누적 생산량)/등록 속도/8`로 계산해 실제 생산 진척을 반영한다. 근무시간만 늘었다고 생산 실적이 증가한 것으로 보지 않는다. 일일 목표 시간은 계획 근무시간, 지정 납기 일일 필수량은 오늘 목표량과 일치한다.
- 실제 생산량·근무시간은 직접 입력한 실적만 저장한다. 추천 계획을 실제 실적으로 저장하지 않는다.

## 달력

2026·2027년 대한민국 공휴일과 대체공휴일을 내장했다. 토/일요일과 지정 공휴일이 겹치면 공휴일로 분류한다. 매주 일요일은 사용자가 정한 주말 분류를 따른다.

회사 휴무일은 선택적으로 `SEUNGJIN_CONFIG.PRODUCTION_PLAN_HOLIDAYS`의 `YYYY-MM-DD` 배열로 추가할 수 있다. 현재 회사별 휴무일 자료는 별도로 등록되지 않았다. 미지원 연도는 공휴일이 없다고 가정하지 않고 계산 불가로 표시한다. 임시공휴일 추가 지정 시 내장 자료를 갱신해야 한다.

## 날짜별 설정

- 저장된 계획이 없는 날짜는 같은 공장·발주의 가장 최근 이전 저장본에서 인쇄 유형·공정/공정 묶음·기계번호만 이어받는다. 전날 저장이 없으면 마지막 저장 날짜를 사용한다.
- 해당 날짜의 저장본이 우선한다. 직접 미배정으로 저장한 기계는 미배정을 유지하며, 해당 인쇄 유형에서 사용할 수 없는 기계는 미배정으로 처리한다. 다른 공장·발주와 미래 날짜의 설정은 가져오지 않는다.
- 생산량·실 근무시간·메모·수정 LOSS 등 날짜별 입력은 복사하지 않는다.

- 오브제는 같은 공장·발주에서 처음 기계를 배정하거나 실제 생산량/근무시간을 저장한 날짜 이전의 미배정 기본 행을 목록·계획 합계에서 제외한다. 이전 저장본도 기계·실적이 없으면 동일하게 제외하며 저장 원문은 변경하지 않는다. 실제 입력·배정이 있는 날짜와 시작일 이후 설정 이월은 유지한다.

- 누적 생산량 바로 옆에 잔여 수량을 읽기 전용으로 표시한다. 발주량에서 선택 날짜까지 누적 생산량을 빼며 최소 0개다. 금일 생산량 편집 시 즉시 갱신한다.
- 날짜 선택란 옆에 요일을 표시하고 직접 선택·이전·다음·오늘 이동 시 갱신한다. 날짜 전용 값을 UTC로 해석해 시간대에 따른 요일 오차를 피한다.
