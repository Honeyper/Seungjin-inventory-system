# 모바일 QR 카메라 선택과 초점

카메라 권한을 받은 뒤 `enumerateDevices()`의 후면 렌즈 이름을 확인한다. 기본/광각을 초광각·망원보다 우선한다. Android의 `camera2 N, facing back` 이름만 있는 경우 작은 번호를 우선하는 휴리스틱이며, 실제 렌즈를 보장하지 않는다. 이름을 구분할 수 없거나 목록 조회가 실패하면 브라우저가 선택한 카메라를 유지한다. 전면으로 명시된 카메라는 변경 목록에서 제외한다.

- 필수 HD 해상도 제한을 제거하고 1280×720, 24fps를 선호값으로 요청한다. 실패하면 동일 카메라의 기본 비디오 모드로 재시도한다. 권한 거절은 재시도하지 않는다.
- 다른 렌즈를 열기 전에 기존 스트림을 종료한다. 추천 렌즈를 열지 못하면 원래 카메라로 복구한다.
- 여러 후면 렌즈가 노출되면 상단 카메라 변경 버튼으로 순환 선택한다. 성공한 수동 선택은 기기에 저장한다. 스캔 목록은 유지한다.
- 재생 직후 및 480ms, 1600ms에 자동 초점을 요청한다. 기본 제약 방식과 advanced 방식을 순서대로 시도한다. 설정값이 다른 모드로 보고되면 성공으로 처리하지 않는다. 설정 메타데이터를 제공하지 않는 브라우저에서는 물리적인 초점 성공을 보장할 수 없다.
- 초점 모드를 바꿀 때 과거 수동 초점 거리 제약을 제거한다. 플래시와 비디오 설정은 유지한다. 관심 지점·노출·화이트밸런스 옵션을 독립적으로 적용해 한 옵션의 실패가 자동 초점을 막지 않게 한다.
- 화면을 눌러 single-shot 초점을 요청한 뒤 continuous 모드로 복구한다. UI는 실제 선명도를 확인하지 못하므로 “초점을 맞췄습니다” 대신 “자동 초점을 다시 요청했습니다”라고 안내한다.
- 스캐너 종료/입력 방식 전환 중 늦게 도착한 스트림도 종료한다. 요청 중 스캐너를 닫았다 다시 열면 최신 화면에서 카메라를 다시 시작한다.

## 검증

`node --test tests/mobile-scanner-camera.test.mjs tests/mobile-scanner-torch.test.mjs`

실제 갤럭시 S21 삼성 인터넷에서 추가 확인이 필요하다. 웹 API 모사 테스트는 렌즈 선택·제약 호환성·플래시 유지·종료 동작을 검증하며 실제 광학 초점을 검증하지 않는다. 기기에서 새로고침한 뒤 QR을 비추고, 흐리면 화면 중앙을 누르거나 카메라 변경 버튼을 사용한다.
