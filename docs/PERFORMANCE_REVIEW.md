# 성능 검토 및 개선 (2026-09-06)

기준 커밋: `ba31835`. 모바일 출고·재고 수정, PC 재고 조회, 공통 Gateway, Supabase 조회·저장 구조와 기존 테스트를 검토했습니다.

## 수정한 문제

| 문제 | 수정 내용 |
| --- | --- |
| 모바일 화면 재진입·새로고침 때 변경 없는 재고도 전체 다운로드 | 기존 `getInventoryVersion` API로 버전을 먼저 확인하고 같으면 기존 목록 사용. 빈 재고도 정상 캐시로 취급 |
| 재고 데이터와 버전의 병렬 조회 중 동시 저장이 일어나면 오래된 데이터에 새 버전이 붙을 가능성 | PC·모바일에서 목록을 요청하기 전에 확인한 버전을 사용. 이전 PC 캐시는 화면에 표시하되 버전은 한 번 다시 검증 |
| QR마다 관련 없는 제품의 박스 배열까지 병합·중복 제거 | 관리 ID·제품 ID별 검색 인덱스로 후보를 좁힌 후 박스 검색. 목록 교체 시 인덱스 재생성 |
| 정확한 박스 ID 검색 실패 후 번호만 같은 다른 박스로 대체될 가능성 | ID가 있으면 정확히 일치하는 박스만 허용. 기존 번호·제품 정보 QR과 별칭 지원 유지 |
| 같은 조회가 동시에 시작되면 요청 중복 | 로그인 세션·조회 종류·조건이 같은 진행 중 요청 공유. 완료·실패 시 제거하고 저장 전후에도 초기화 |
| 관리자 화면이 숨겨져도 알림·서버 사용량 조회 | 숨겨진 화면의 주기적 요청 생략. 다시 활성화하면 갱신 |
| 로그인과 외부 스캐너에서도 카메라 QR 해석 라이브러리 다운로드 | 카메라를 열 때 `jsQR` 지연 로드. 동시 로드 합치기, 실패 후 재시도 지원 |

모바일 조회 도중 로그아웃하면 이전 계정의 응답이 화면에 다시 적용되지 않도록 했습니다. 실제 업무 저장 요청이나 서버의 수량·상태 검증은 기존 경로를 사용합니다.

## 검증

- 수정 전 기존 테스트 99개 통과.
- 수정 후 전체 테스트 113개 통과. 추가 테스트는 실제 함수를 실행해 버전 변경, 빈 목록, 통신 실패·재시도, 로그아웃, 기존 QR 호환, 잘못된 박스 ID, 중복 조회와 저장 간 경합을 확인합니다.
- Edge/Chromium에서 390×844, 360×740, 1440×1000 화면으로 확인했습니다. 모바일 목록 갱신, 스캔 후 새로고침 시 목록 복원, 카메라 진입, PC 재고 새로고침을 테스트용 API·가상 카메라로 검증했으며 JavaScript 오류는 없었습니다.
- 실제 iPhone Safari·삼성인터넷 기기에서의 촬영·배터리 소모 측정은 포함하지 않았습니다.

## 측정 결과

합성 데이터 1,000개 제품·30,000개 박스로 기존 코드와 수정 코드를 같은 Node.js 환경에서 실행했습니다. 마지막 제품 QR 검색 12회 중앙값은 약 **131.9ms → 0.19ms**였습니다. 인덱스가 준비된 반복 검색 기준이며 카메라 영상 해석·네트워크·화면 렌더링 시간은 제외합니다.

동일 데이터의 전체 목록 JSON은 5,805,080바이트, 버전 JSON은 19바이트였습니다. 변경 없는 재조회에서는 이 전체 목록 전송을 생략합니다. HTTP 헤더와 실제 운영 데이터 크기는 제외한 비교입니다.

카메라를 사용하지 않는 첫 화면은 `jsQR.min.js` 130,601바이트(약 128KiB)의 다운로드·해석을 생략합니다. 카메라 스캔 최초 진입 시에는 한 번 불러옵니다.

## 남아 있는 구조적 비용

- 최초 재고 조회는 여전히 전체 목록을 받으며, 같은 박스 정보가 전체·활성·출고 목록에 중복 포함됩니다. 이를 한 번만 전송하려면 서버와 PC·모바일 사이 응답 형식을 함께 변경해야 합니다.
- 모바일 전체 재고 캐시는 아직 동기식 `localStorage`를 사용합니다. 큰 목록은 브라우저 저장 한도에 걸려 페이지를 다시 열 때 전체 조회가 필요할 수 있습니다. PC는 이미 IndexedDB를 사용합니다.
- 관리자·모바일 JS/CSS는 파일 규모가 큽니다. 이번에는 업무 기능을 대규모로 분리하지 않고 반복 처리·통신과 초기 로딩을 개선했습니다.

운영 데이터 삭제, DB 스키마 변경, Supabase/GAS 서버 배포는 이 변경에 필요하지 않습니다.
