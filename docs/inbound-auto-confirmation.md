# 입고 시 자동 실물 확인

- 새 입고의 완박스·잔량 박스에 입고 날짜/시간을 `lastInventoryCheckedAt`으로 저장합니다. 등록 버튼을 누른 현재 시간이 아니라 실제 입고 시각이 기준입니다.
- 확인 시각이 없는 기존 박스도 조회 시 해당 입고 시각을 최초 확인으로 해석합니다. 기존 DB의 이력을 일괄 덮어쓰지 않습니다. PC의 이전 캐시에도 같은 규칙을 적용하며, 모바일 캐시는 새 버전으로 다시 읽습니다.
- 직접 확인한 박스는 그 기록을 우선합니다. 단순 입고 수정·자리 변경으로 확인 기간을 다시 시작하지 않습니다.
- 기존 한국시간 달력 한 달 규칙을 그대로 사용합니다. 9월 29일 12:00 입고는 10월 29일 12:00부터 미확인입니다. 다음 달에 같은 날짜가 없으면 말일로 계산합니다.
- 출고대기·출고완료·보류·폐기 및 수량이 없는 박스는 실물 확인 대상에서 제외합니다. 재고정리 가능 여부와는 별도 규칙입니다.
- 입고 날짜가 없거나 잘못되면 자동 확인을 만들지 않습니다. 미래 입고일은 해당 시각 전까지 확인 완료로 집계하지 않습니다.
- 상세보기의 최종 확인일도 박스의 확인 기록과 입고 기준 시각을 반영합니다. 백업에서 복구한 예전 박스에 최초 확인 값이 없어도 입고 날짜가 있으면 동일하게 계산됩니다.

검증: `tests/inbound-auto-confirmation.test.mjs`, `tests/inventory-confirmation-cycle.test.mjs`. 생성·잔량·월말·한 달 경계·기존 입고·이전 캐시·직접 확인 우선·단순 수정 보존을 포함합니다. 운영에서 읽은 9월 29일 NP-0001 입고 37박스(10:20), KHE-0001 입고 24박스(12:00)는 최초 확인 값이 없고 보관 상태였습니다. 새 규칙은 이 입고 시각을 기준으로 확인 완료를 계산합니다.
