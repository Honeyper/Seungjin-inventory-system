# 입고 첨부파일 업로드

입고 등록·수정은 첨부파일 URL이 확인된 뒤에만 저장한다. 파일 선택 시에는 브라우저 안에서 읽기·명세서 최적화만 준비한다. 원래 Drive 폴더 구조, 파일 형식, 바이트, 설명, 상속된 접근 권한을 유지한다.

- 사진은 최대 8개, base64 합계 약 8MB 단위로 전송한다. 큰 단일 파일은 별도 요청으로 처리한다.
- 폴더의 가장 긴 유효한 공통 경로를 재사용한다. 폴더 ID 캐시는 최대 6시간이며 삭제·이름 변경·휴지통 상태를 확인하고 잘못된 경로는 다시 탐색한다.
- 파일 데이터를 검증하면서 해독한 결과를 저장에서도 사용한다.
- 5MB 이하 파일은 Drive multipart 업로드로 파일 내용·이름·설명·부모 폴더를 한 요청에 기록한다. 사진은 최대 4개, 합계 4MB 단위로 동시 저장한다. 단일 파일은 5MB까지 처리하며 5MB 초과 파일은 기존 DriveApp 경로를 사용한다.
- Drive API가 비활성화됐다는 명시적인 응답에는 기존 저장 방식을 사용한다. 네트워크 단절이나 불명확한 쓰기 결과는 자동으로 재전송하지 않는다.
- 묶음 안의 다른 파일이 실패해도 성공 응답을 받은 파일 정보는 먼저 보존한다. 재시도 시 파일별 ID와 문맥·내용 지문이 일치하는 완료 정보를 재사용한다. 캐시 장애 시에도 원래 저장 경로는 작동한다.
- OAuth 토큰은 서버 안에서만 사용한다. 클라이언트에는 기존 파일·폴더 URL만 반환한다. 실행 시간 로그는 파일 개수·바이트 수·검증 및 저장 시간만 기록한다.

## 2026-10-28 검증

DEV 전용 일회용 함수에서 512KB 테스트 파일을 비교했다. 단일 파일은 기존 저장 약 1.6~2.0초, 파일과 설명을 함께 저장하는 방식은 약 1.15~1.49초였다. 4개 파일 비교에서는 기존 순차 저장 15,528ms, 실제 수정 함수를 사용한 동시 저장 4,905ms였다. 이는 DEV의 해당 테스트에서 측정한 서버 저장 구간이며, 사용자 파일의 전송·폴더 탐색·화면 처리 시간을 포함한 전체 업로드 속도를 보장하는 수치는 아니다.

측정 폴더는 각 실행의 finally에서 휴지통으로 이동했고, DEV의 측정 함수와 배포는 측정 전 상태로 복구했다. 운영 입고 데이터나 사용자의 기존 첨부파일은 측정에 사용하지 않았다.

## 2026-11-12 공통 사진 경로

제품 이미지와 출고 불량사진에도 같은 multipart 저장 경로를 적용했다. 프론트는 최대 8개·base64 합계 8MB로 요청을 묶고, 서버는 기존처럼 한 번에 4개·해독 후 합계 4MB까지만 Drive에 동시 저장한다. 5MB 초과 단일 파일은 기존 DriveApp 저장 경로를 유지한다.

제품 사진은 원래의 링크 공개 열람 권한과 리소스 키를 유지하며, 출고 불량사진의 권한은 변경하지 않는다. 제품·출고 사진도 파일별 완료 정보를 저장해 일부 실패 후 성공한 사진을 다시 만들지 않는다. 제품 이미지 단일 요청/응답 필드는 기존 클라이언트와 호환된다. 사진의 크기·형식·바이트는 변환하지 않는다.

브라우저 관련 확인은 `node tools/browser-smoke.cjs --uploads-only`로 수행할 수 있다. 전체 브라우저 스모크의 기존 생산계획 작업자 선택기 검사는 현재 UI와 맞지 않아 별도 갱신이 필요하다.

### DEV 실제 저장 구간 측정

512KB 시험 파일 4개로 기존 출고 사진 경로와 변경 경로를 비교했다. 파일 저장 구간은 22,209ms → 13,550ms(약 39% 단축), 그중 폴더 준비는 7,722ms → 7,437ms였다. 원본 바이트 해시는 모두 일치했다. 별도 제품 사진 1개(512KB) 저장도 8,729ms였으며 링크 공유와 원본 일치를 확인했다. 입고 사진 4개(각 512KB)는 8,597ms로 저장됐고 원본 일치를 확인했다. 이는 DEV의 격리된 임시 폴더를 사용한 서버 구간 측정이며, 사용자의 전체 전송 대기시간을 뜻하지 않는다.

측정 중 Google Apps Script 응답에서 `DEADLINE_EXCEEDED` 오류가 한 번 관찰됐다. 측정용 요청은 자동 재전송하지 않았으며, 운영 사진이나 업무 데이터는 측정에 사용하지 않았다.
