# 모바일 선택 박스 이동과 재고조사

- `선택 박스 이동` 및 개별 카드의 `자리이동`은 스캔한 박스를 이동하고 실물 확인 시각을 갱신한다.
- 같은 관리 ID에서 이번 조사에 등록하지 않은 실물 확인 대상 박스는 `미확인 + 미지정`으로 저장한다. 수량은 유지한다.
- 출고대기·출고완료·보류·폐기 및 수량 0 박스, 다른 관리 ID는 초기화하지 않는다. 전량 이동 및 사출재고 전환은 기존 동작을 유지한다.
- 조사 ID는 모바일 페이지에서 공유한다. 같은 조사에서 먼저 이동한 박스는 이후 분할 처리·재시도로 초기화하지 않는다. 미처리 스캔 목록을 저장할 때 조사 ID도 함께 저장한다. 완료한 목록이 없는 상태에서 페이지를 다시 열면 새 조사로 시작한다.
- 명시적 미확인은 `inventoryConfirmationSource: survey-unconfirmed`로 구분한다. 입고 자동 확인은 이를 덮어쓰지 않는다. 이후 실물 확인 또는 조사 이동 시 해제된다.
- 이전 확인 시각 및 마지막 알려진 위치는 각각 `lastInventoryCheckedAt`, `inventoryLastKnownStorage`에 보존한다.
- 서버는 이동과 미등록 박스 초기화를 같은 변경 묶음으로 저장한다. 확인창에서 미등록 박스 초기화를 안내한다.

검증: `node --test tests/mobile-move-survey.test.mjs tests/mobile-inventory-bulk-move.test.mjs`
운영 데이터의 일괄 초기화 또는 소급 적용은 하지 않는다.

## 같은 위치 확인 및 실물 확인 위치 지정

- 개별 이동과 선택 박스 일괄 이동에서는 현재 위치를 다시 선택할 수 있다. A → A도 실물 확인 시각을 갱신하며 기존 조사 규칙대로 미등록 박스를 미확인·미지정으로 바꾼다.
- 같은 입고 건 전량 이동은 목적지에 이미 있는 박스를 계속 제외한다.
- 재고 실물 확인 범위는 화면을 열 때마다 `스캔한 박스`가 기본 선택된다.
- 실물 확인 화면에서 보관 위치를 지정하면 확인 대상인 스캔 박스에만 해당 위치를 저장한다. `기존 위치 유지`를 선택하면 위치는 그대로다. 최종 확인창에 저장할 위치를 표시한다.
- 실물 확인은 스캔하지 않은 박스를 변경하지 않는다. 출고대기·출고완료·보류·폐기 및 수량 0 박스는 서버에서도 확인 대상으로 허용하지 않는다.
