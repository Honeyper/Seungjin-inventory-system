# 출고량 기준 발주 자동 완료

발주에 명시적으로 연결된 입고의 정상 출고완료 박스 수량 합계가 총 발주량 이상이면 `발주완료`로 분류한다. 총 발주량이 0인 항목은 자동 완료하지 않는다. 같은 제품이라는 이유만으로 다른 발주의 출고량을 합산하지 않는다.

- 99.99%처럼 화면 표시를 반올림한 수치는 완료 판정에 사용하지 않는다. 정확한 수량으로 비교하며 초과 출고도 완료에 포함한다.
- 반출·이관·재고조정·출고대기·보류·폐기는 정상 출고량에서 제외한다.
- 기존의 수동 마감은 `임의 완료` 상태와 기록을 유지한다. 취소 발주는 자동 완료하지 않는다.
- 서버의 `getPurchaseOrders` 조회에서 최신 출고량과 자동 완료 여부를 함께 산출한다. 별도의 수동 완료 쓰기 요청이나 반복 작업은 필요 없다. 저장된 수동 상태를 덮어쓰지 않는다.
- 출고 취소 또는 발주량 변경으로 출고 비율이 100% 미만이 되면 다음 조회에서 자동 완료가 해제된다. 수동 완료는 유지한다.
- 발주 현황 진입과 새로고침 시 최신 출고량을 조회한다. 목록은 자동/수동 완료 항목을 기본 숨기며 `발주완료 항목 보기` 버튼으로 함께 볼 수 있다. 검색 및 정렬은 유지한다. 완료 상태 필터를 직접 선택해도 조회할 수 있다. 초기화는 기본 숨김으로 돌아간다.
- 자동 완료 행은 수동 완료 버튼 대신 `자동 완료`를 표시한다. 수동 완료 행은 기존 `완료 취소` 동작을 유지한다.
- 신규 입고 선택 및 생산계획 대상에서 완료 발주를 제외한다. 기존 입고 수정에서 현재 연결 발주는 보존한다.
